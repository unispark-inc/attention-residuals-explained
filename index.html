Attention Residuals Explained

Replacing fixed residual connections with learned attention over depth

Read the Paper Official Implementation

The Problem with Standard Residual Connections

In standard Transformers, each layer's output is added to a residual stream with fixed unit weights. This creates three fundamental issues:

1

No Selective Access

All layers receive the same aggregated state. No way to selectively access specific earlier representations.

2

Irreversible Information Loss

Once outputs are summed, individual layer contributions cannot be recovered.

3

Output Magnitude Growth

Deeper layers must produce larger outputs to remain influential in the accumulated sum.

The Key Insight

Instead of fixed summation, use learned attention to selectively aggregate layer outputs based on content.

Standard Residual

hl = hl-1 + fl(hl-1)

Fixed unit weights

Attention Residual

hl = Σ αi→l · vi

Learned attention weights

How It Works

Each layer computes attention weights over all previous layer outputs using learned pseudo-query vectors.

Step 1

Pseudo-Query Vectors

Each layer l has learnable query vectors Ql that represent what information it needs.

Step 2

Compute Attention Weights

Calculate attention scores between queries and all previous layer outputs:

αi→l = softmax(Ql · viT / √d)
Step 3

Weighted Aggregation

Aggregate previous outputs using the learned weights:

hl = Σi=0l-1 αi→l · vi

Block AttnRes: The Practical Variant

Full attention over all layers has O(Ld) memory cost. Block AttnRes partitions layers into blocks and attends over block-level representations instead.

Full AttnRes

Memory: O(Ld)

Each layer attends over all previous outputs

Block AttnRes

Memory: O(Nd)

N blocks << L layers

Key Benefit

Block AttnRes achieves ~1.25x compute reduction while matching or exceeding baseline performance by enabling efficient selective access to earlier representations.
